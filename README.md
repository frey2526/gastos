# Gestor de gastos (versión de práctica)

Programa de línea de comandos para apuntar gastos en memoria.

## Qué hace

1. Agregar un gasto (nombre, monto y categoría).
2. Listar todos los gastos.
3. Ver el total.
4. Ver el total por categoría.
5. Ver los gastos mayores a 100 €.

## Cómo ejecutarlo

```bash
python gastos.py
```

## Aprendido con este proyecto

- Listas de diccionarios
- Funciones y validación de entrada
- Comprensiones: `sum(... for ...)`, filtros `[... for ... if ...]`
- `set` para obtener las categorías únicas
